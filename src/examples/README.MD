# Examples

## Purpose
- This folder serves to host initial tests and provided demos for the various API providers currently under consideration, and allow for easier analysis of the API's patterns and parameters

## Limitations
- At the time of writing, only free APIs are currently being considered, with preference placed on providers which offer scalable and affordably priced packages for future scalability
- API Providers won't necessarily provide demos in the desired programming language of choice, however these will be kept in the same language as the demo (inclusive of JS)
